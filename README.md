# Персональний нотатник

Лабораторна робота №1 з дисципліни «Технології веб-розробки».

**Варіант 20 — персональний нотатник (щоденник).**

## Можливості

- Додавання нотаток із заголовком, текстом, датою та тегами.
- Редагування та видалення з підтвердженням.
- Перевірка полів регулярними виразами з підсвічуванням помилок.
- Пошук за заголовком і текстом із підсвічуванням збігів.
- Фільтрація за тегами та сортування за датою.
- Лічильник символів із попередженням при наближенні до ліміту.
- Збереження нотаток у localStorage.
- Адаптивне оформлення.

## Технології

HTML5, CSS3 та JavaScript ES6+ без сторонніх бібліотек і фреймворків.

## Структура проєкту

- `index.html` — структура сторінки та форма.
- `styles.css` — оформлення й адаптивність.
- `app.js` — класи Note і NotebookManager, робота з DOM, подіями та localStorage.

## Локальний запуск

1. Завантажити репозиторій через Code → Download ZIP.
2. Розпакувати архів і відкрити папку у Visual Studio Code.
3. Встановити розширення Live Server від Ritwick Dey.
4. Натиснути правою кнопкою на index.html та вибрати Open with Live Server.

Нотатки зберігаються у браузері для адреси, за якою відкрито застосунок. Вони не завантажуються в репозиторій GitHub.
